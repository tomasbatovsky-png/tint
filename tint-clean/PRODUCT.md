# Tint Clean MVP — Product Definition

Tint is a digital sixth sense for text on the web.

It does not summarize pages.
It does not block content.
It does not replace user thinking.

Tint lightly reveals the psychological atmosphere pushed through visible text.

## Core principle

The web constantly pushes emotional and cognitive pressure:
- urgency
- aspiration
- manipulation
- usefulness
- calm
- synthetic repetition
- status
- trust

Tint makes those pressures perceptible.

## MVP principle

Text first.

Tint should work on:
- headlines
- paragraphs
- comments
- reviews
- CTA buttons
- product copy
- video titles
- blog posts
- landing pages

Tint should NOT tint:
- full pages
- thumbnails
- full cards
- ambient backgrounds
- platform-specific layouts

## Atmospheres

### Green
Grounded, human, calm, restorative.

### Blue
Informational, neutral, analytical, useful.

### Orange
Attention-heavy, urgent, manipulative, hype-driven.

### Gray
Synthetic, templated, automated, low-human-signal.

### Violet
Aspiration, status, prestige, transformation, desire.

## UX rule

Tint should feel like a perceptual shadow.

Not a warning.
Not a moderation system.
Not a highlighter.

The feeling should be:

"I can sense the pressure of this text."
