# Tint Clean MVP

Clean rebuilt MVP for Tint.

## Concept

Tint is a digital sixth sense for text on the web.

It lightly visualizes the psychological atmosphere of visible text:
- grounded
- informational
- attention-heavy
- synthetic
- aspirational

## Principles

- text first
- hover-only tint
- no page wash
- no thumbnail tinting
- no full-card overlays
- no platform spaghetti

## Atmospheres

- green = grounded / human / restorative
- blue = informational / neutral / useful
- orange = urgency / hype / attention pressure
- gray = synthetic / templated / automated
- violet = aspiration / status / desire

## Structure

- extension/ = Chrome extension
- worker/ = optional backend endpoint

## Goal

A very small, stable, universal MVP.
